# hackathon-playbook

웹사이트 구축형 AI 해커톤(웹 IDE + Codex CLI, 180분)용 작업 규칙과 단계별 프롬프트 모음입니다.
과제 코드나 정답은 들어 있지 않습니다.

## 파일
- `AGENTS.md` — Codex가 매번 읽는 작업 규칙. 워크스페이스 루트에 둡니다. 맨 아래 '과제 정보' 칸은 P1에서 Codex가 README를 보고 채웁니다.
- `PLAYBOOK.md` — 사람이 보는 프롬프트 모음(P0~P12). 필요한 프롬프트를 복사해 터미널에 붙여넣습니다.

## 쓰는 순서
1. `AGENTS.md`, `PLAYBOOK.md`를 작업 폴더에 둡니다.
2. 터미널에서 `codex` 실행 → P0부터 순서대로.
3. 사용 사실은 DECISIONS.md에 "사전에 준비한 본인 템플릿을 사용했다"고 적어 둡니다.
